Master Data Review Queue

When invoice extraction creates a new item automatically, we keep the order moving but raise a review task for admin. Admin can approve, correct item master fields, set margin, and mark the master-data record as governed.

Open Review Queue
View Source Order
See Notification Center
Recommended rule: auto-created item remains usable for the current order, but stays in Pending Review until admin approves master data. This avoids blocking operations while keeping governance.
What triggers this? A parsed invoice row does not match an existing item, so AAS creates an item in ERP and immediately opens a review task.
Who sees it? `ADMIN` users via sidebar badge, top-header notification pill, and optional dashboard card.
What can admin change? Item name, category, UOM, packaging, vendor HSN, default margin, GST, and review status.
